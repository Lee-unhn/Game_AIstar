# AI 星靈物語　課堂美術素材包

這套素材以星塔的琥珀燈光、靛藍夜色、苔綠和潮青串起畫面。共有 25 張可單獨使用的 PNG，另附生成圖集與提示詞。素材由 ImageGen 為本專案生成，學員可在本專案內使用、改色、裁切與延伸。

| 資料夾 | 有哪些素材 | 可放在哪裡 |
|---|---|---|
| `scenes/` | 星港標題、微光鎮、草徑、霧港、星塔 | 標題、對戰背景、劇情插圖。標題 960×640，其餘 480×320 |
| `creatures/` | 灰燼貂、汐泡獺、芽角鹿、夜翅蛾、苔石龜、窯斑螈、林冠龜、笑燈靈 | 選角、圖鑑、對戰。透明底，檔名對應星靈 id |
| `people/` | 旅人、照護員、霧港漁夫、星塔守望者 | 單格角色插圖、NPC 對話、角色介紹 |
| `items/` | 星晶、凝露瓶、圖鑑手冊 | 背包與任務提示 |
| `props/` | 港燈、深草、常綠樹、木路牌、石拱門 | 地圖裝飾和劇情示意 |
| `source/` | 場景、星靈、人物與道具的原始圖集、生成提示詞 | 重新裁切或生成同風格變體 |

## 接到自己的 issue

1. 先讀 issue 的可改檔案，再從表格挑圖。把原檔留在素材包，變體用新檔名。
2. 預設遊戲沿用原本的封面、16×16 星靈點陣和對戰背景。這套 PNG 適合用在圖鑑插頁、故事插圖或素材練習。若 issue 允許試做插圖，`examples/illustrated-render.js` 示範如何離線讀圖及缺圖時回到文字點陣。
3. 新星靈仍要提供 16×16 文字點陣。人物與道具是單格素材。行走方向、動畫、地圖碰撞與遇敵規則沿用既有遊戲資料。
4. 操作時確認縮小後仍看得懂輪廓，圖片不蓋住名稱、血條或對話。新增和改圖時，PR 附使用畫面與素材來源。

提示詞見 [source/PROMPTS.md](source/PROMPTS.md)，可沿用風格、光線和輪廓設定，再換成自己的原創主題。
