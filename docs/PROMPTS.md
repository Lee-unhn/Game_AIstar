# 可以複製給 AI 的提示詞

全部複製貼上，把 `＜＞` 裡的字換掉。

## 接任務

```text
請先讀 AGENTS.md。
拿最新的 main，列出任務板上標籤「任務」而且沒人認領的 issue，用表格列給我：編號、標題、難度。
我選好之後，重讀那張 issue 的最新留言，確認沒人接，再替我認領、開分支、動手。
```

## 加一隻新星靈

```text
請先讀 AGENTS.md 和 docs/DATA_FORMAT.md。
任務是 #＜編號＞。請新增一隻星靈：
- 名字：＜中文名＞
- 屬性：＜焰／森／潮／光／影＞
- 外型：＜一句話描述，例如藍色的小狐狸，尾巴結霜＞
- 定位：＜野生／起始＞

做法：
1. 看 data/monsters 目前最大編號，新檔案用最大編號＋1。
2. 16×16 文字點陣圖要看得出外型，面向左邊，每列剛好 16 個字元。
3. 學的招式只能用 data/moves 裡現有的 id。
4. 只新增這一個檔。名字和圖都要原創。
5. 跑 node tools/check.mjs，修到通過。
6. 告訴我怎麼在遊戲裡看到牠。如果野生星靈要出現在草叢，那要改地圖檔，先問我。
```

## 加一個招式

```text
請先讀 AGENTS.md 和 docs/DATA_FORMAT.md。
任務是 #＜編號＞。請新增一個招式：
- 名字：＜中文名＞
- 屬性：＜焰／森／潮／光／影＞
- 感覺：＜一句話描述，例如威力大但常打不中＞

做法：
1. 看 data/moves 目前最大編號，新檔案用最大編號＋1。
2. 數值參考現有招式，威力落在 35 到 65。
3. 名字要原創。
4. 跑 node tools/check.mjs，修到通過。
5. 告訴我哪隻星靈適合學這招。改 learnset 是另一個檔，先問我。
```

## 加一張地圖

```text
請先讀 AGENTS.md 和 docs/DATA_FORMAT.md。
任務是 #＜編號＞。請新增一張地圖：
- 名字：＜中文名＞
- 樣子：＜一句話描述，例如長滿草的山谷，中間有一條河＞
- 接在哪裡：＜從哪張地圖的哪一邊走過去＞
- 會遇到的星靈：＜星靈 id 和等級範圍＞

做法：
1. 看 data/maps 目前最大編號，新檔案用最大編號＋1。
2. 每列一樣長，圖塊只用 docs/DATA_FORMAT.md 列出的字元。
3. spawn、NPC、出口都要放在可走的格子上。
4. 兩張地圖要互相有出口，玩家才走得過去也走得回來。
5. 跑 node tools/check.mjs，修到通過。
6. 雙擊 index.html 實際走一次，把結果告訴我。
```

## 提修改意見

```text
請先讀 AGENTS.md 的「提修改意見」。
看一下 ＜檔案或功能＞，把你發現的問題和想法整理出來。先不要改任何檔。
每一則都寫：哪個 AI、看到什麼、在哪個檔、建議怎麼改、嚴重度（重大／一般／僅記錄）。
只寫你實際看到的事。
有 gh 就開 issue 並加上標籤「意見」和「AI 意見」。沒有就把內容給我，我自己貼到表單。
```

## 解衝突

```text
我追平 main 時遇到衝突。請先讀 AGENTS.md。
1. 列出有衝突的檔案，用白話說明兩邊各改了什麼。
2. 兩邊都要保留，除非它們互相矛盾。矛盾就先問我，不要自己決定。
3. 刪掉 <<<<<<<、=======、>>>>>>> 記號。
4. 跑 node tools/check.mjs，確認通過。
5. 告訴我接下來要在 GitHub Desktop 按什麼。
不要 force push。
```
